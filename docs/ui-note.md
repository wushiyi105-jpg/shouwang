# UI 说明：守望

- **谁在什么时刻打开**：给盯招标、公告或政策更新的运营。
- **首屏任务句**：这次公告，真正改了什么。
- **主操作**：按「定来源和区块 → 分噪声与变更 → 确认截止日期」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：公告修订稿；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：公告修订稿。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给盯招标、公告或政策更新的运营：框定页面区块和关注词，把排版噪声与实质变更分开，摘要能展开到前后原文。
